# Prueba Practi Front 1

Una aplicación de práctica para desarrollo front-end con HTML, CSS y JavaScript vanilla.

## Características

- **Interfaz moderna y responsiva** con gradientes y animaciones
- **Área interactiva** para saludar usuarios
- **Contador funcional** con incremento, decremento y reset
- **Estilos CSS modernos** con transiciones y efectos visuales
- **JavaScript vanilla** sin dependencias externas

## Estructura del Proyecto

```
prueba_practi1_front/
├── index.html          # Página principal
├── css/
│   └── styles.css      # Estilos CSS
├── js/
│   └── app.js          # Lógica JavaScript
├── package.json        # Configuración del proyecto
└── README.md           # Este archivo
```

## Instalación y Uso

1. **Clonar el repositorio** (si es necesario)
2. **Instalar dependencias** para el servidor de desarrollo:
   ```bash
   npm install
   ```

3. **Ejecutar la aplicación**:
   ```bash
   npm start
   ```
   Esto iniciará un servidor local en `http://localhost:3000`

4. **Abrir en el navegador**: La aplicación se abrirá automáticamente

## Funcionalidades

### Área Interactiva
- Ingresa tu nombre en el campo de texto
- Haz clic en "Saludar" para recibir un saludo personalizado
- También puedes presionar Enter después de escribir tu nombre

### Contador
- **Incrementar**: Suma 1 al contador
- **Decrementar**: Resta 1 al contador  
- **Reiniciar**: Vuelve el contador a 0

## Tecnologías Utilizadas

- **HTML5**: Estructura semántica
- **CSS3**: Estilos modernos con Flexbox y Grid
- **JavaScript ES6+**: Funcionalidad interactiva
